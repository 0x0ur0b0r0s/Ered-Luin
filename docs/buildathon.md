# Buildathon project description

Ered Luin explores how on-chain and other public observations can be presented as traceable evidence before a person makes a decision. The demonstration emphasizes provenance, freshness, clear uncertainty, and a visible boundary between an advisory summary and human authorization.

The public project is a conceptual, offline-friendly sample. Its mock observations are synthetic, and its policy example is intentionally small. The repository does not include production scoring, strategy, enforcement, custody, or execution systems.

## Demonstration flow

1. Represent observations in an `EvidencePacket` with a source and observation time.
2. Link an advisory `IntelligencePacket` to the evidence it summarizes.
3. Surface stale or missing evidence for human review in the example workflow.
4. Keep the result as a local demonstration artifact.

The sample illustrates a product direction; it is not a claim of investment performance, production readiness, or live execution capability.
