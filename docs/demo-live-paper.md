# Ered Luin paper-demo recording

The accompanying [`demo-live-paper.mp4`](demo-live-paper.mp4) is a screen recording of the D1 paper-demo flow. It shows an agent proposal, the evidence/rationale path, persisted Nansen observation batches, and the deterministic paper gate.

The proposal and rationale are paper-only. Nansen supplies persisted market evidence with provider, endpoint, value, quality, and observation time. The recording does not connect a wallet, request a signature, call Base RPC, broadcast a transaction, or use live funds.

The visible result is a blocked paper path because execution, signing, submission, browser wallet, and Base RPC remain disabled.
